# Discord-Bot

Small discord.js bot for AMA recap, abuse reports, and an NFT claim-link DM. Archived snapshot, as-is.

This tree is a **new public commit** with no git history. The original private archive is `eulertools/Discord-Bot-archive`.

## What was built (EN)

`index.js` listens on a few hard-coded channel IDs (`/ama`, `/report`, `/nft`) and DMs the user. The committed bot token was **removed** from `config.json` (empty string). Put a token in `config.json` locally or copy `config.example.json` — do not commit it.

No contract deployments.

## Qué se construyó (ES)

Bot de Discord mínimo. El token no está en este snapshot.
